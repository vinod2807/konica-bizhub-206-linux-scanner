# Recon artefacts – Round 1 (Phase 1)

All files captured 2026-10-19 on `alpine-jwm` (Alpine 3.24, kernel 6.18.57).

| File | What it is | Command that produced it |
|---|---|---|
| `lsusb-v.txt` | Full descriptors for 132b:232b | `sudo lsusb -v -d 132b:232b` |
| `lsusb.txt` | Bus listing | `lsusb` |
| `lsusb-t.txt` | USB topology tree | `lsusb -t` |
| `dmesg-usb.txt` | Kernel messages for `usb 1-2` / KONICA / 132b | `sudo dmesg \| grep -iE 'usb 1-2\|konica\|132b'` |
| `sane-find-scanner.txt` | SANE low-level USB probe | `sane-find-scanner` |
| `scanimage-L.txt` | SANE device list | `scanimage -L` |
| `sane-libs.txt` | Installed SANE backend libs | `ls /usr/lib/sane` |
| `sane-conf-listing.txt` | Permissions/list of `/etc/sane.d` | `ls -la /etc/sane.d /etc/sane.d/dll.d` |
| `dll.conf.snapshot` | SANE dll config | `cat /etc/sane.d/dll.conf` |
| `dll.d.snapshot` | SANE dll.d entries | `cat /etc/sane.d/dll.d/*` |
| `epsonds.conf.snapshot` | Epson backend config | `cat /etc/sane.d/epsonds.conf` |
| `environment.txt` | Kernel + distro | `uname -a`, `/etc/os-release` |
| `apk-relevant.txt` | Relevant installed packages | `apk info -v \| grep ...` |
| `sane-supported-konica.txt` | SANE supported-devices page, Konica section | `curl http://www.sane-project.org/sane-mfgs.html` |
| `sane-konica-minolta-wiki.txt` | kainhofer wiki: SANE backends for Konica | `curl https://wiki.kainhofer.com/hardware/sane_konica_minolta` |
| `bizhub-scan-wiki.txt` | kainhofer wiki: bizhub SCL scanning protocol (C203/363, LAN) | `curl https://wiki.kainhofer.com/hardware/bizhub_scan` |
| `sane-magicolor-man.txt` | `sane-magicolor` man page / supported devices | `curl https://man.archlinux.org/man/sane-magicolor.5.en` |

Nothing in this directory was generated by sending data to the scanner.
